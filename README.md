# Portfolio Website — Moises Navas

A responsive, accessible single-page portfolio built with vanilla HTML, CSS, and JavaScript. Demonstrates semantic HTML, responsive layout, keyboard-accessible UI, and a simple contact form integration.

## Tech Stack

HTML · CSS · JavaScript

## Project structure

- [index.html](index.html) — single-page entry
- [script.js](script.js) — interactive behaviors (tabs, menu, contact form)
- [styles/styles.css](styles/styles.css) — main styling and design tokens
- [styles/responsive.css](styles/responsive.css) — responsive overrides
- assets/ — images, icons and notes (see [assets/project-requirements.md](assets/project-requirements.md))

## Features

- Mobile-first, responsive design and projects grid
- Accessible tabbed content with keyboard navigation (Arrow keys, Enter/Space)
- Sticky navigation with skip link for screen readers
- Project cards with overlay links to live demos and repositories
- Contact form posting to a Google Apps Script endpoint (configurable in `script.js`)
- Small design system with color tokens and utility classes
